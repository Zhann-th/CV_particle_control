# NeuroVision AI — Real-Time 3D Hand Gesture & Spatial Control Platform

![NeuroVision AI Badge](https://img.shields.io/badge/AI-Spatial_Gesture_Control-2ecc71?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Stack-Three.js_|_MediaPipe_|_WebGL-00f2fe?style=for-the-badge)

NeuroVision AI is an interactive, browser-based spatial control platform powered by MediaPipe hand tracking, Three.js 3D WebGL rendering, and real-time gesture telemetry.

## 🌟 Key Features
- **Real-Time 3D Hand Tracking:** 21 3D spatial landmark points tracked with MediaPipe & WebGL.
- **Interactive Spatial Controls:**
  - ✋ **Open Palm:** Rotate 3D particle cosmos.
  - 🤏 **Pinch:** Compress & scale 3D sphere.
  - ✌️ **Peace Sign:** Trigger particle wave pulse.
  - ✊ **Fist:** Gravitational singularity pull.
- **Interactive Demo Mode:** Instant interactive canvas simulation when webcam permission is pending.
- **Customizable 3D Constellations:** Cyber Emerald, Plasma Cyan, and Nebula Violet color themes with dynamic particle density controls.

## 🚀 Quick Start
1. Open `index.html` in any web browser.
2. Click **Start Camera** for real webcam tracking, or interact with the demo canvas using mouse/clicks.
